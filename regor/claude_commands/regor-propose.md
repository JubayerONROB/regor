# Follow-up experiment proposals

Plan the next iteration.
1. `regor propose`, then `regor -v proposals list`.
2. Add reasoning to the most relevant proposals: what was learned, remaining uncertainty, possible outcomes, resources.
3. Present them ranked to the researcher. Do not approve them yourself.
4. Check `regor loop status` for stopping and review requirements.

Global rules (see CLAUDE.md): never fabricate results, citations or sources; never run paid, remote or long jobs without a researcher-granted approval; never edit runs/raw or runs/metadata.
