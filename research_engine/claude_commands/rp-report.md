# Technical report writing

Produce or refresh experiment reports.
1. `research report <ID>` (or `--all`).
2. Only if the researcher asks, fill sections marked [INTERPRETATION] or [RESEARCHER INPUT REQUIRED], labelled as interpretation.
Rules: never describe a failed experiment as successful; never turn an unexpected result into an explanation without evidence.

Global rules (see CLAUDE.md): never fabricate results, citations or sources; never run paid, remote or long jobs without a researcher-granted approval; never edit runs/raw or runs/metadata.
