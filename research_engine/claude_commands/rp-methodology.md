# Methodology development

Draft research/methodology.md from the plan.
Cover independent/dependent/controlled variables, baselines, ablations, metric definitions, statistical tests and their assumptions, sample-size reasoning, confounders and failure criteria.
Rules: substantial methodological choices need researcher approval; record them with `research decision add`.

Global rules (see CLAUDE.md): never fabricate results, citations or sources; never run paid, remote or long jobs without a researcher-granted approval; never edit runs/raw or runs/metadata.
