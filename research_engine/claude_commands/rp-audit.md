# Manuscript audit

Audit the manuscript.
1. `research manuscript build`, then `research -v manuscript audit`.
2. Explain each FAIL and WARNING and fix the source text, never the audit.
3. Walk the researcher through the human review checklist in manuscript/audit/audit_report.md.
Rules: never call the manuscript submission-ready while any FAIL remains.

Global rules (see CLAUDE.md): never fabricate results, citations or sources; never run paid, remote or long jobs without a researcher-granted approval; never edit runs/raw or runs/metadata.
