# Experiment analysis

Analyse validated runs.
1. `research analyze <REF> --compare <OTHER...> --metric <m> --plot --name <name>`.
2. Read analysis/comparisons/<name>.md: test rationale, assumption checks, effect size, interval, adjusted p, excluded runs.
3. Respect the interpretation guard. Inconclusive means inconclusive.
Rules: no cherry-picking, no axis manipulation, no significance wording without the analysis.

Global rules (see CLAUDE.md): never fabricate results, citations or sources; never run paid, remote or long jobs without a researcher-granted approval; never edit runs/raw or runs/metadata.
