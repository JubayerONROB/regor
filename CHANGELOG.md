# Changelog

## 0.1.0 (2026-10-04)

First public release.

- `regor` CLI: project init with 14 domain profiles, dataset registration and validation,
  immutable run records, local / Kaggle / manual-import execution, result validation,
  assumption-checked statistics, comparisons and figures with provenance, 21-section
  experiment reports, claim registry, reference verification (Crossref/arXiv), follow-up
  proposals with stopping rules, and manuscript drafting, rendering, auditing and journal
  checklists.
- Kaggle backend verified on real Kaggle with CPU and GPU kernels.
- Synthetic end-to-end demo; 91 automated tests; CI on Linux, macOS and Windows.
